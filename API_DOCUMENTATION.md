# API documentation

Two groups of endpoints exist:

- **Implemented (M0 spike)** — served by `spikes/m0-pipeline`, covered by tests.
- **Planned** — proposed contracts for later milestones; not implemented.

All JSON errors use one shape:

```json
{
  "error": {
    "code": "CAPACITY_EXCEEDED",
    "message": "Maximum concurrent playback sessions reached"
  }
}
```

| HTTP | `code`               | Meaning                                                            |
| ---- | -------------------- | ------------------------------------------------------------------ |
| 400  | `VALIDATION_FAILED`  | Body failed schema validation (`issues` lists the problems)        |
| 403  | `FORBIDDEN`          | Missing, invalid or expired stream token                           |
| 404  | `NOT_FOUND`          | Unknown content, session, segment or subtitle track                |
| 502  | `SOURCE_UNAVAILABLE` | Torrent metadata or media probe could not be obtained              |
| 502  | `TRANSCODE_FAILED`   | Encoder failed for the requested segment                           |
| 503  | `CAPACITY_EXCEEDED`  | Session or disk limit reached; honour `Retry-After`                |
| 503  | `SEGMENT_NOT_READY`  | Segment not produced within the wait timeout; honour `Retry-After` |

## Implemented (M0 spike)

> No user authentication yet (M3). The spike binds to `127.0.0.1` by default.

### `GET /healthz`

`200` → `{ "status": "ok", "sessions": 0, "torrents": 0 }`

### `GET /v1/catalog`

Lists the authorized catalog. Only these items can be played.

```json
{
  "items": [
    {
      "id": "m0-test-pattern",
      "title": "M0 Test Pattern (synthetic)",
      "license": "CC0-1.0",
      "licenseUrl": "https://creativecommons.org/publicdomain/zero/1.0/",
      "attribution": "Generated by this repository (ffmpeg testsrc2 + sine). No third-party rights."
    }
  ]
}
```

### `POST /v1/playback/sessions`

Creates a playback session: acquires the torrent, probes the media, plans the
rendition and prepares subtitles.

Request:

| Field                    | Type                                               | Default  | Notes                                                             |
| ------------------------ | -------------------------------------------------- | -------- | ----------------------------------------------------------------- |
| `contentId`              | string                                             | —        | Must exist in the catalog                                         |
| `quality`                | `"auto" \| "480p" \| "720p" \| "1080p" \| "2160p"` | `"auto"` | Capped to the source and client; `2160p` is passthrough-only (M2) |
| `startPositionSec`       | number ≥ 0                                         | `0`      | Resume position; the first encoder job starts at this segment     |
| `preferredAudioLanguage` | ISO 639 code                                       | —        | Selects the audio stream                                          |
| `capabilities.hevc`      | boolean                                            | `false`  | Client can decode HEVC                                            |
| `capabilities.maxHeight` | integer                                            | `1080`   | Largest height the client wants                                   |

Response `201`:

```json
{
  "sessionId": "fef0c93b-691a-4381-b4c6-b965c099e9b2",
  "masterPlaylistUrl": "/v1/hls/fef0c93b-…/1794435416.hG37sTpe…/master.m3u8",
  "expiresAt": "2026-11-11T22:16:56.000Z",
  "durationSec": 90.006583,
  "video": { "width": 1920, "height": 1080, "quality": "1080p", "codecs": "avc1.640028" },
  "subtitles": [
    { "language": "ar", "name": "العربية", "forced": false, "rtl": true },
    { "language": "en", "name": "English", "forced": false, "rtl": false }
  ],
  "decisions": [
    {
      "code": "COPY_ELIGIBLE_NOT_IMPLEMENTED",
      "message": "Source video is Safari-compatible and could be remuxed, …"
    }
  ]
}
```

`masterPlaylistUrl` is absolute when `PUBLIC_BASE_URL` is set, otherwise
relative to the API origin. `decisions` explain every non-obvious choice
(codes: `QUALITY_CAPPED`, `UHD_REQUIRES_PASSTHROUGH`, `COPY_ELIGIBLE_NOT_IMPLEMENTED`,
`VIDEO_TRANSCODE_REQUIRED`, `AUDIO_TRANSCODE_REQUIRED`, `HDR_TONEMAP_MISSING`, `NO_AUDIO`).

Errors: `400`, `404` (not in catalog), `502 SOURCE_UNAVAILABLE`, `503 CAPACITY_EXCEEDED`.

### `POST /v1/playback/sessions/:id/heartbeat`

Keeps a paused session alive. `204`, or `404` if the session is gone.

### `DELETE /v1/playback/sessions/:id`

Stops the encoder and deletes the session's files. `204` or `404`.

### HLS delivery

All under the capability prefix `/v1/hls/:sessionId/:token/`, where `token`
is `<expiryUnixSec>.<HMAC-SHA256>` bound to the session. Players only ever
follow relative URIs from `master.m3u8`.

| Path                        | Content-Type                    | Notes                                                                                     |
| --------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------- |
| `master.m3u8`               | `application/vnd.apple.mpegurl` | One variant (+ `SUBTITLES` group)                                                         |
| `video/index.m3u8`          | same                            | Complete VOD playlist, 6 s segments, `EXT-X-MAP`                                          |
| `video/init.mp4`            | `video/mp4`                     | Canonical fMP4 init segment (waits for the first encode)                                  |
| `video/seg-<n>.m4s`         | `video/iso.segment`             | Produced on demand; may wait up to `SEGMENT_WAIT_TIMEOUT_SEC`, else `503` + `Retry-After` |
| `subs/<lang>/index.m3u8`    | `application/vnd.apple.mpegurl` | Single-segment WebVTT playlist                                                            |
| `subs/<lang>/subtitles.vtt` | `text/vtt; charset=utf-8`       | Normalised UTF-8 WebVTT with `X-TIMESTAMP-MAP`                                            |

Caching: playlists `private, no-cache`; segments and subtitles
`private, max-age=3600, immutable`. CORS: only origins listed in `ALLOWED_ORIGINS`.

### Diagnostic player

`GET /player/?autostart=1&engine=native|hlsjs&quality=720p&content=<id>` —
M0 test page only, not the product UI.
